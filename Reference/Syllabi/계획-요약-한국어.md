# 클래스 캘린더 앱 — 진도·페이지 및 실라버스 계획 요약

**문서 목적:** 교사·관리자용 인쇄 가능 요약 (구현 전 계획)  
**대상 앱:** Class Calendar Planner (`index.html`)  
**작성 기준:** 2026년 봄학기 샘플 실라버스 PDF 7종 분석 반영  

---

## 1. 이 계획이 하는 일

| 목표 | 설명 |
|------|------|
| **요일 빠른 선택** | 월수, 수금, **월금**, 화목(T/T) 등 학원 일정에 맞는 버튼 추가 |
| **PDF 실라버스 → 수업 유형** | 제공하신 PDF 7개를 바탕으로 **미리 정해진 수업 유형** 등록 |
| **날짜별 진도·페이지** | 강의 계획표의 **「교재 / 상세」** 칸에 수업·숙제 내용 저장 |
| **숙제 붙여넣기** | 토론 `Day 1`…, RC `Unit (1/2)`… 형식 텍스트를 표에 자동 매칭 |

**표시 위치:** 진도·페이지는 주로 **강의 계획표 + 인쇄/PDF**에 나옵니다. 달력 날짜 칸에 긴 문구를 항상 보이게 하는 것은 **선택 사항(나중 단계)** 입니다.

| 구분 | 프로그램 | 주당 수업 | 수금·월수·월금·화목 네 변형? |
|------|----------|-----------|------------------------------|
| **주 1회** | **토론**; **GR** (가람바다/샘물/여울) | **요일 1개** (월/화/수 중 PDF 기준) | **아니오** — 화목(화+목) 아님 |
| **주 2회** | RC, Green-Blue, WR+SP, 심독; **GR 별마루(월금)** | 2요일 | RC만 네 변형; 별마루는 **월금만** |

**토론** — 앱에 이미 「주 1회」(`debateMonthly`).

**GR(문법)** — PDF 5종 분석 완료. 대부분 **주 1회·하루만**(예: 샘물 T반 = **화요일만**, 화+목이 아님). **별마루 GR만 월·금 2회**, 20단원. → 아래 5.4절.

## 5. 샘플 PDF 7종과 수업 유형

### 5.1 같은 과목, 다른 요일 (RC 샘물-여울)

**진도 내용은 동일**하고 **수업 요일만** 다릅니다.

| PDF (요약) | 반 | 요일 패턴 |
|------------|-----|-----------|
| 샘물-여울 RC [M반] (수금) | M | 수 · 금 |
| 샘물-여울 RC [M반] (월수) | M | 월 · 수 |
| 샘물-여울 RC [T반] (화목) | T | 화 · 목 |

→ 앱에서는 **과목당 하나의 커리큘럼** + **네 가지 일정 변형** 으로 설계합니다.

### 5.2 모든 과목 — 네 가지 일정 변형 (필수)

| 변형 | 요일 | 비고 |
|------|------|------|
| **수금** | 수 · 금 | 대부분 샘플 PDF 기준 |
| **월수** | 월 · 수 | M반 대체 |
| **월금** | 월 · 금 | |
| **화목** | 화 · 목 | **모든 과목에 T반용 변형 필수** |

**대상:** RC 샘물-여울, Green-Blue RC, Red Phonics, 가람바다 심독, 가람바다 GR 등.  
예: `Green-Blue RC (화목)`, `Red Phonics (화목)`.

**PDF:** 화목 전용 PDF는 현재 **RC만** 있음. 다른 과목은 **수금 PDF와 동일한 단원·진도**를 쓰고, **요일만** 화목으로 달력에 배치합니다.

### 5.3 프로그램별 참고 (수업 구조)

| 프로그램 | 샘플 PDF | 수업 구조 | 총 회차 (예) |
|----------|----------|-----------|--------------|
| Green-Blue RC | 수금 | Unit (1/2)·(2/2), 12단원 | 24회 |
| Red Phonics | 수금 | 회당 1 Unit, 중간 교재 변경 | 별도 처리 (화목도 동일 진도) |
| 가람바다 심독 | 수금 | Unit (1/2)·(2/2) | 24회 |
| 가람바다 GR (2025) | (PDF 재확인) | GR 프로그램 | 추후 확정 |

**Red Phonics** 는 라벨·일정 방식이 특수하지만, **화목 변형**도 같은 진도를 화·목 요일에 배치합니다.

### 5.4 GR / 문법 (Grammar 폴더 PDF 5개)

| 프리셋 | 교재 | 주당 | 앱 요일 |
|--------|------|------|---------|
| 가람바다 GR M | 가람바다 | 1회 | **수요일** |
| 샘물 GR T | 샘물 | 1회 | **화요일** (화목 아님) |
| 여울 GR M | 여울 | 1회 | **월요일** |
| 여울 GR T | 여울 | 1회 | **화요일** |
| 별마루 GR M | 미리내/별마루 | **2회** | **월금** (월·금) |

회차당 `Unit N`, `<수업>`/`<과제>` 내용을 **교재/상세**에 넣습니다. 구현 시 PDF를 `Reference/Syllabi/Grammar/`에 복사합니다.

## 6. 수업 만들기 — 단계별 (구현 후)

### 5.1 학기·달력 설정

1. 상단 **캘린더 이름**, **학기 시작 월**, **표시 개월** 설정  
2. 필요 시 **+ Add Event** 로 공휴일·평가 기간·어린이날 등 등록  

### 5.2 「+ Add Class」로 수업 추가

| 순서 | 화면 항목 | 하는 일 |
|------|-----------|---------|
| 1 | **수업 이름** | 예: `26 SP 샘물-여울 RC M반` |
| 2 | **수업 유형 (Class type)** | 예: `RC 샘물-여울 (수금)` 또는 `Green-Blue RC (화목)` — **모든 과목: 수금·월수·월금·화목** |
| 3 | (자동 입력) | 총 수업 수(24), **수업 요일**, 기본 교재, 단원 목록 등 |
| 4 | **빠른 선택** | 월수 / 수금 / 월금 / 화목 등 재확인 |
| 5 | **시작일·종료일** | 학기 기간 |
| 6 | **교시, 레벨, 학년, 월별 교재** | 필요 시 수정 |
| 7 | **저장 (Save Class)** | 달력에 수업 막대 표시 |

### 5.3 강의 계획표 (진도·페이지)

| 순서 | 작업 | 결과 |
|------|------|------|
| ① | **캘린더에서 새로고침** | 날짜·주·회차·Unit (1/2) 행 생성 |
| ② | **프리셋 페이지 적용** (PDF 반영 시) | 수업/숙제 내용 → **교재 / 상세** |
| ③ | **단원에서 페이지 채우기** | 단원별 스피킹/라이팅 → 각 회차 |
| ④ | **붙여넣기로 가져오기** | 미리보기 → 적용 |
| ⑤ | 표에서 **교재 / 상세**, **메모** 수정 | |
| ⑥ | **저장** | 브라우저 저장 · JSON보내기에 포함 |

**순서:** ① 새로고침 **후** ②~④ 진행 (그렇지 않으면 회차·날짜가 맞지 않음).

### 5.4 인쇄

- 수업 편집 창: **강의 계획표 인쇄 (Print syllabus)**  
- 또는 전체 **인쇄** 옵션에서 강의 계획표 포함  
- **교재 / 상세** 열에 수업·숙제·페이지가 출력됩니다

## 6. 데이터 흐름 (이해용)

```
달력 일정 (요일 + 학기 기간 + 공휴일/이벤트)
        ↓  「캘린더에서 새로고침」
강의 계획표 행 (날짜, 주, 회차, Unit 1 (1/2) …)
        ↓  단원 / 붙여넣기 / PDF 프리셋
교재·상세 (수업·숙제·페이지) + 메모
        ↓  인쇄
진도표 PDF
```

- **교육과정 단원:** 단원마다 스피킹·라이팅 **페이지** (묶음)  
- **강의 계획표 행:** **날짜마다** 인쇄용 최종 내용  
- **새로고침** 후에도 이미 입력한 **교재 / 상세** 는 가능한 한 **유지**
