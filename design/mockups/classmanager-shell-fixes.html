What changed

1
Homework ID collision fixed. Not visible on screen — the Classroom segment's underlying data-segment now reads homework-tracking instead of reusing homework, matching Schedule → Homework copy's own id. Labels stay as-is: "Homework copy" (Schedule) and "Homework" (Classroom).
2
Tools → Books renamed to "Debate Books." Matches the naming pattern its siblings already use (Debate Teams, Debate Scores), so it no longer collides in meaning with Class Setup → Books.
3
"Waiting" lock/sync state now has a defined treatment. Amber like Pending, but with a dashed border so teachers can tell "someone's waiting to edit" apart from "an action is pending" at a glance. Legend below.
4
Classroom's 8-segment row shown with its scroll-fade cue. This is the densest row in the app and the one most likely to crowd out on narrow screens with Korean labels — the fade at the right edge signals there's more to scroll to.
5
Command Center left out of the tab row (still hidden/dev-preview) so the mockup doesn't imply a reachable path where the canonical-homes table's "links out" note doesn't currently apply.
6
Global functions moved to the very top row. Sync/lock status, print, language, theme, help and account now live in Row 1, above the zone tabs, instead of the lock/sync bar sitting in a separate sticky strip below the header card. Sync affects every zone's data, not just the one you're currently looking at, so it now reads as shell-level chrome rather than page-content chrome. It also means it survives when a teacher scrolls zone tabs on mobile — it's anchored above them, not competing with them for space.
