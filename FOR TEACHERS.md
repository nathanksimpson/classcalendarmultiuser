# For teachers — Class Calendar (team)

## What you need

1. **Bookmark** your school calendar link (from your lead teacher).
2. **Kakao account** — the same email your admin added.

## How to sign in

1. Open your bookmark.
2. Click **Login with Kakao**.
3. Approve Kakao if asked.

If you see **Access not granted**, send the email shown on that screen to your lead teacher. You do **not** need to find any Kakao ID yourself.

## Editing

- Pick a calendar from the **Team calendar** dropdown.
- Changes save automatically.
- If someone else is editing the same calendar, you will see a banner — click **Take over editing** when it is your turn.

## Password login

Only if your admin gave you a temporary email + password — use the form on the login page.

## You do not need to

- Run any `.bat` file or server
- Open files from a shared folder
- Know what "localhost" means

Just use the bookmark.
